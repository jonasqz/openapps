API and MCP before buttons

Whatever a person can click, an agent can call.

Every function exists as an API and an MCP tool before it gets a button. An agent works with its own identity and sees only the tools it was granted. Your own coding assistant creates, ships and rolls back apps without anyone opening Coolify.

  1. 01

    Create the app

    From the starter template, with its own schema and database role.

  2. 02

    Request the deploy

    The agent names a version. The platform does the rest.

  3. 03

    Pass the review gate

    Scanners and the UI linter run before anything reaches Coolify.

  4. 04

    Grant access

    Exactly one permission per grant, written to the audit log.

  5. 05

    Roll back if needed

    One call back to the previous version.

Review gate

Nothing goes live unchecked.

Before every deploy, machines check the rules. The checks are always on, in every edition. An AI security report can sit on top, with your own key, but never in place of the scanners.

gitleaks

Secrets

A key in the diff stops the deploy.

semgrep

Code

Known unsafe patterns are blocked.

ui linter

Interface

Only components and tokens from the design system.

manifest

Contract

The app does what its manifest says, and no more.

● pass · projects 0.1.0

All four checks green. The control plane tells Coolify to build, and the app goes live behind the shared login.

● blocked · projects 0.1.1

gitleaks found a key in the source. The deploy stops here, the agent gets the finding, and nothing reaches the server.

One permission model

One sentence decides every access, for people and agents alike.

Whogroup sales may Do whatread on Which resourceapp crm .
grant group:sales read app:crm

Default deny

New routes, tools and tables stay closed until a grant opens them.

Apps carry no auth code

The gateway checks every call. The database role limits every query, without BYPASSRLS.

Agents get the overlap

A run may do only what the agent may do and what the person who started it may do.

Bring your own key

Any model. Your key. No key, no calls.

The platform calls a model only with a key you set in your own environment. There is no default model. Without a key, everything works as before, and agent features stay off.

The bar for version 1

Seven checks, each with proof.

Version 1 is done when all seven pass in a real run. They are the definition of done, and we publish the proof next to the code.

  1. 1

    From prompt to live app in under 15 minutes

    Created and deployed over MCP, without opening Coolify.

  2. 2

    No way in without the login

    Every app domain, before and after a Coolify update.

  3. 3

    Apps cannot see each other

    Until a grant opens a table or view. Revoking works at once.

  4. 4

    A planted secret is blocked

    The review gate stops the deploy.

  5. 5

    Rollback in under two minutes

    One command, back to the previous version.

  6. 6

    Agents see only granted tools

    Without a grant they are blocked, and every call is logged.

  7. 7

    A fresh agent ships an app on its own

    With only the agent guide, the skill and the platform MCP.

The whole platform on your laptop.
